Free **Agent Skills** (`SKILL.md`) that help Claude, Claude Code, OpenAI Codex and other AI agents make meetings shorter and more useful: audit your calendar and your team's meeting system, write agendas, prepare briefs, capture notes and actions, send follow-ups and run decision meetings.

By [**Afeez Adebayo**](https://afeezadebayo.com) · [Browse online](https://afeezadebayo.com/skills-md/productivity/meetings-calendar/) · [LinkedIn](https://www.linkedin.com/in/afeez-adebayo/) · [X](https://x.com/za_icon)

Part of the [Productivity skills](https://github.com/afeezadebayo/productivity-skills) library.

## All skills

| Skill | What it does |
|---|---|
| [`calendar-audit`](calendar-audit) | Measures where your time goes and designs a better week |
| [`meeting-system-audit`](meeting-system-audit) | Audits a team's recurring meetings and designs a leaner set |
| [`meeting-agenda`](meeting-agenda) | Agendas with purpose, outcomes, owners and time boxes |
| [`meeting-prep-brief`](meeting-prep-brief) | A two-minute brief before important meetings |
| [`meeting-notes-actions`](meeting-notes-actions) | Notes that capture decisions, actions and owners |
| [`meeting-follow-up`](meeting-follow-up) | Follow-up messages that keep actions moving |
| [`decision-meetings`](decision-meetings) | Meetings that end with a decision |

More skills in this set are planned. See the [full list online](https://afeezadebayo.com/skills-md/productivity/meetings-calendar/).

## Install

```bash
git clone https://github.com/afeezadebayo/meetings-calendar-skills.git
# Claude Code
cp -r meetings-calendar-skills/meeting-agenda ~/.claude/skills/
# Codex and other agents
cp -r meetings-calendar-skills/meeting-agenda ~/.agents/skills/
```

In Claude.ai or Claude Desktop, zip a single skill folder and upload it under **Settings → Capabilities → Skills**.

Then ask your agent, for example: *"Audit my calendar for the last four weeks"* or *"Write an agenda for Thursday's planning meeting."*
